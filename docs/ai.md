# AI-анализ: назначение и ограничения

## Что извлекается

Анализ получает только текст объявления и каталог вымышленных ЖК. Он может вернуть название объекта, адрес, застройщика, телефоны, признаки предложения оплаты, сумму, активную продажу и гипотезы R2/R3. У каждого фактора-гипотезы есть цитата и уверенность.

По умолчанию `AI_PROVIDER=local-ml` включает локальную логистическую модель и извлечение полей правилами. Модель обучена на 60 оригинальных синтетических русскоязычных фразах; признаки — слова и пары слов, веса хранятся в `models/payment-linear-v1.json`. Обучение воспроизводится командой `node scripts/train-payment-model.mjs`. Модель классифицирует предложения и сохраняет точный фрагмент; отрицания дополнительно проверяются правилами. Код модели не определяет R1 и не меняет итоговый балл без человека.

В тесте новая формулировка «Закрепление выбранной квартиры производится после оплаты резерва» распознаётся как возможное предложение платежа. Обычная реклама шоурума, бесплатная бронь и банковский депозит проверяются как отрицательные случаи. Эти проверки не являются оценкой качества на реальной выборке. Выход модели не калиброван; хорошая оценка не доказывает нарушение. Казахскоязычный анализ отдельно не обучался и не валидировался.

`AI_PROVIDER=rule-based` сохраняет отдельный режим только на правилах. Он явно обозначается и не считается ML/LLM-моделью. Опциональный адаптер использует OpenAI Responses API и JSON Schema, если в `.env` явно заданы `AI_PROVIDER=openai` и `AI_API_KEY`; для `AI_PROVIDER=deepseek` используется отдельная переменная `DEEPSEEK_API_KEY`, ключи провайдеров не взаимозаменяются. При ошибке провайдера или невалидной структуре приложение возвращается к локальным правилам. Тексты, переданные внешнему провайдеру, покидают локальный компьютер; отправляйте туда только материалы, которые разрешено обрабатывать таким способом.

## Контроль цитат и человека

Перед сохранением AI-результата приложение проверяет, что цитата оплаты и каждая цитата гипотезы — точные подстроки исходного текста. Отсутствие цитаты блокирует соответствующий вывод. Связь с ЖК не принимается автоматически: предложенный кандидат хранится отдельно и требует подтверждения аналитика.

После подтверждения связи создаются гипотезы. Они остаются `AI_HYPOTHESIS` и не меняют балл. Для подтверждения аналитик должен сохранить точное доказательство и источник; для объявления API дополнительно проверяет цитату в исходном тексте. AI не устанавливает юридический статус и не предлагает R1.

## Обработка данных

- Встроенная база содержит только явно вымышленные демо-записи.
- Анализ объявления использует введённый текст; URL не загружается и не скрейпится.
- Не загружайте персональные, конфиденциальные или закрытые документы в демонстрационный экземпляр.
- Не трактуйте уверенность модели как вероятность нарушения или доказательство факта.
- Проверьте оригинальный материал и документируйте источник до подтверждения фактора.
