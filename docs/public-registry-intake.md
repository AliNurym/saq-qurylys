# Открытые данные для реестра пилота

Проверено 19 октября 2026 года. Это подготовка данных для существующего приложения, а не подтверждение полноты реестра 48 ЖК или законности привлечения средств.

**Граница хакатонной модели:** все отметки `yellow` при 0 баллов в результатах импорта ниже записаны по прежней пилотной модели и являются историческими. В текущем хакатонном PDF-скоринге 0 баллов попадает в зелёную числовую зону, а `needsReview=true` отдельно показывает, что сведения требуют проверки. Эти исторические импортные протоколы не являются результатом пересчёта по формуле Codemasters 8.0.

## Пакет по городу: 10 записей источника, 8 кандидатов для импорта

После исследования одной карточки проверен публичный поисковый запрос, используемый каталогом Homeportal. Метод `POST` здесь выполняет поиск, без учётной записи и без изменения данных: `https://api.homeportal.kz/api/v1/getobjects`, тело `{"authority":"","city_id":73,"is_paginate":true,"region_id":16,"search":"","build_status":"2","status":"2,3"}`. Идентификаторы города/региона совпадают с публичной карточкой №1141. Это выборка каталога при указанных фильтрах, а не согласованный состав пилота.

Ответ на `2026-10-19T10:53:53.697Z`: `total=10`, одна страница, `next_page_url=null`. SHA-256 исходных 31 860 байт: `9f7c7919161cafed31241430cf0e40d3aaad7f4c64a9cb0e1903d2bb12af7b3d`. Для каждого из десяти идентификаторов получена публичная детальная карточка. Сверены город/регион, название, БИН, адрес и координаты между поиском и деталями; хеш каждого исходного ответа записан в происхождении.

- [CSV с восемью кандидатами](examples/homeportal-oskemen-candidates.csv): PARK LINE (1505), Satti City (1452), Viva Life (1398), Asyl Tau (1375), ASYLTAS — участок 1 (1331), ASYLTAS — участок 2 (1330), Orda (1329), Золотой квадрат (1141).
- [Происхождение всех десяти записей](examples/homeportal-oskemen-provenance.json): ссылки, даты наблюдения, хеши исходных ответов, сведения источника, причины исключения из CSV. Дата обновления самой карточки неизвестна и указана как `null`. Контактные телефоны и адреса электронной почты в пакет не перенесены.
- №1487 оставлен для ручной проверки: координаты `(0, 0)`. №1428 также отложен: координаты источника примерно в 185,5 км от медианы остальных ненулевых точек выборки. Проверка расстояния с порогом 25 км — аналитический фильтр качества, не официальная граница города и не доказательство ошибочности исходных сведений. Координаты не исправлялись догадкой или геокодированием.
- Две записи ASYLTAS не объединялись: у них разные идентификаторы, адреса, участки и реквизиты документов. Принадлежность каждой записи к пилоту и применимость разрешения к блокам/очередям требуют отдельной проверки.

Пакет прошёл штатный импорт в SQLite `:memory:` с режимом `working`: ровно восемь записей, все `UNKNOWN`, yellow, 0 баллов, `needsReview=true`, без demo-записей. Подтверждены сохранение двух отдельных ASYLTAS и ведущих нулей БИН, отклонение повторного импорта с прежним digest без добавления дублей. Основная база не открывалась. Результат проверки сохранён в `homeportal-batch-verification.json` в локальном каталоге материалов ниже. Это дополнительный сценарий подготовки данных, не увеличение числа постоянных автоматических тестов приложения.

Перед рабочим импортом оператор должен проверить свежесть сведений, состав пилота и отмеченные ограничения. В поле источника указать Homeportal, ссылку на каталог и «публичные сведения, не проверены МИО; дата — дата наблюдения»; дата наблюдения — `2026-10-19`. Исходный однострочный CSV №1141 ниже входит в новый пакет: импортировать оба файла последовательно нельзя, это дублирование одного кандидата.

Это утверждения источника на момент наблюдения, ещё не проверенные МИО.

Источник указывает гарантию ДПГ-25-16-078/194 от 18.08.2025 и плановый ввод 01.11.2026. Дата выдачи гарантии и плановая дата ввода не являются датой обновления всей карточки. Отдельная дата актуальности ответа неизвестна. Значение `construction_progress: "0"` не перенесено в фактическую готовность: нет подтверждённой даты и метода оценки. Файл [homeportal-1141-candidate.csv](examples/homeportal-1141-candidate.csv) содержит одну подготовленную запись. Он не загружен в основную базу. Поля СМР, ПСД, экспертизы и сведения о регистрации ДДУ оставлены незаполненными. Гарантия перенесена только как текст с пометкой о необходимости проверки. Несколько пятен в карточке источника нельзя автоматически считать несколькими самостоятельными объектами пилота или считать гарантию применимой к каждому из них без проверки документов.

## Почему это ещё не 48 паспортов

Выполненные поиски по официальным сайтам не дали подтверждённого полного перечня именно 48 строящихся ЖК на текущую дату. Это ограничение проведённого поиска, а не доказательство отсутствия такого перечня. Исторические сообщения, перечни завершённых домов, объекты закупок и результаты поиска по числу «48» не заменяют согласованный состав пилота. Счётчик национального каталога также не является количеством ЖК Усть-Каменогорска.

Следующий шаг по данным — согласовать с владельцем пилота состав объектов и единицу учёта (ЖК, очередь, блок, участок), затем сопоставить каждую запись с официальными документами. Один полученный кандидат не закрывает критерий приёмки 48 полных паспортов и не означает подключения Казреестра, земельного кадастра или реестра ДДУ.
